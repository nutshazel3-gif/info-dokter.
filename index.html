Konfigurasi Apps Script Web App

Hubungkan endpoint Google Sheets ke portal web

Dapatkan URL ini dari menu Deploy > New deployment > Web app (Execute as: Me, Access: Anyone) pada proyek Apps Script yang berisi Code.gs Anda.

info Struktur Spreadsheet yang digunakan:

Backend membaca 4 sheet:
• DOKTER — master data dokter
• INFORMASI_DOKTER — data izin / perubahan kuota / perubahan jam (kolom JENIS_INFORMASI membedakan jenisnya)
• DETAIL_INFORMASI_DOKTER — rincian tanggal mulai tidak praktik & tanggal kembali praktik
• LOG — jejak audit setiap SIMPAN / EDIT data

Dashboard ini memanggil ?aksi=get_dashboard, yang mengembalikan data gabungan dari INFORMASI_DOKTER + DETAIL_INFORMASI_DOKTER, sudah diberi status HARI_INI / AKAN_DATANG oleh backend.

Catatan penting: nilai kolom JENIS_INFORMASI pada sheet INFORMASI_DOKTER harus persis salah satu dari: DOKTER_IZIN, PERUBAHAN_KUOTA, atau PERUBAHAN_JAM, agar dashboard bisa mengelompokkan data ke tab yang tepat. Sesuaikan pilihan pada form input (perawat.html) Anda jika nilainya berbeda.

Ringkasan Code.gs (Google Apps Script)

Cuplikan endpoint utama. Kode lengkap ada di proyek Apps Script Anda.

/**
 * ============================================================
 * INFORMASI DOKTER
 * BACKEND / API GOOGLE APPS SCRIPT
 * ============================================================
 *
 * SHEET:
 *   DOKTER
 *   INFORMASI_DOKTER
 *   DETAIL_INFORMASI_DOKTER
 *   LOG
 *
 * GET:
 *   ?aksi=get_dokter
 *   ?aksi=get_dashboard
 *   ?aksi=get_info_by_id&id=INFO-xxxx
 *
 * POST JSON:
 *   {"aksi":"simpan_info", ...}
 *   {"aksi":"update_info", ...}
 * ============================================================
 */

const NAMA_SHEET_DOKTER = 'DOKTER';
const NAMA_SHEET_INFO = 'INFORMASI_DOKTER';
const NAMA_SHEET_DETAIL = 'DETAIL_INFORMASI_DOKTER';
const NAMA_SHEET_LOG = 'LOG';
const TIMEZONE = 'Asia/Makassar';

function doGet(e) {
  try {
    const p = e && e.parameter ? e.parameter : {};
    const aksi = clean_(p.aksi);

    if (aksi === 'get_dokter') {
      return json_({ status: 'success', data: getDokter_() });
    }
    if (aksi === 'get_dashboard') {
      return json_({ status: 'success', data: getDashboard_() });
    }
    if (aksi === 'get_info_by_id') {
      const id = clean_(p.id || p.ID_INFORMASI);
      if (!id) return json_({ status: 'error', message: 'ID_INFORMASI wajib diisi.' });
      const data = getInfoById_(id);
      if (!data) return json_({ status: 'error', message: 'Data tidak ditemukan.' });
      return json_({ status: 'success', data: data });
    }
    return json_({ status: 'success', message: 'API INFORMASI DOKTER aktif.', api: true });
  } catch (err) {
    return json_({ status: 'error', message: err.message });
  }
}

// ... doPost, simpanInfo_, updateInfo_, getDashboard_, dan fungsi util lainnya
// mengikuti kode backend yang sudah berjalan di Apps Script Anda saat ini.
// (Lihat file Code.gs asli di proyek Apps Script Anda untuk kode lengkapnya.)
